## Summary of Deep Learning Architectures and Techniques

### Sequence Modeling and Transformers
Sequence modeling has advanced significantly, moving from RNNs (LSTMs, GRUs) to the **Transformer architecture**, which leverages attention for parallel processing. Transformers are fundamental in NLP (powering models like GPT and BERT for tasks like summarization, translation, and code generation) and are expanding into biology (e.g., protein folding). They are categorized into **Encoder-only** (e.g., BERT), **Decoder-only** (e.g., GPT), and **Encoder-Decoder** (e.g., T5) variants, with **PrefixLM** being a related structure. The core mechanism relies on **Scaled Dot-Product Attention** and **Multihead Attention**. The standard Transformer structure includes an **Encoder** (self-attention without causal masking) and a **Decoder** (with causal masking and cross-attention), augmented by **residual connections** and **Layer Normalization (LN)**. Initial setup involves **Tokenization**, **Embedding**, and **Positional Encoding**.

To enhance performance and efficiency, several innovations have been introduced:
*   **Efficiency:** Techniques like **FlashAttention-2/4** minimize non-matmul FLOPs, while **MQA/GQA** speeds up inference by sharing K/V projections. **Speculative Decoding** further accelerates generation.
*   **Long Sequences:** Quadratic $O(N^2)$ scaling is addressed by sub-quadratic methods such as **Reformer** ($O(N\ln N)$) and **BigBird** ($O(N)$) using sparse/hashing techniques, and **Performer** which achieves linear time complexity via Fourier random features.
*   **Modern Enhancements:** Activations like **SwiGLU**, normalization like **RMSNorm**, and positional encodings such as **RoPE** and **ALiBi** are used. Inference benefits from **KV caching**.

**Multimodality** extends Transformer capabilities beyond text by "tokenizing" other data types: images are converted into patches (**Vision Transformers**), and speech signals are processed via spectrograms (**Conformer, Whisper**). Models like LLaVA demonstrate effective **transfer learning** when fine-tuned on visual datasets, and various Transformer architectures are used for **text-to-image generation** (e.g., DALL-E 1, Parti).

### Convolutional Neural Networks (CNNs)
CNNs excel at processing spatial data by building hierarchical features through local connections and weight sharing. Key components include **Pooling Layers** for down-sampling, **ReLU Layers** for non-linearity, and **Fully Connected Layers** governed by a **Loss Layer**. Training involves tuning **Padding**, **Stride**, and **Filter/Kernel Size**. Regularization employs both **Empirical** (e.g., **Dropout**) and **Explicit** methods (e.g., **Weight Decay**). CNNs are broadly applicable across image processing, **Video Analysis**, **Time Series Forecasting**, and NLP, and can incorporate attention or transfer learning.

### Generative Models: GANs and Advanced Variants
**Generative Adversarial Networks (GANs)** utilize a minimax game. Prominent variants include **Wasserstein GANs (WGANs)** (which enforce Lipschitz constraints), **Conditional GANs (cGANs)** for targeted outputs, **InfoGAN**, **StyleGAN** (for tracking synthesis), **CycleGAN** (for unsupervised image-to-image translation using $L_{cycle}$), and BigGAN (which incorporates self-attention for high-resolution outputs).

### Other Generative and Feature Learning Models
**Autoencoders (AEs)** are used for dimensionality reduction; variations include **Denoising AEs (DAEs)** and **Variational AEs (VAEs)**, where $\beta$-VAEs help in feature disentanglement. **Invertible Data Augmentation** enables semantic-preserving transformations if the underlying Markov kernel is invertible.

### Associative Memory, Graphs, and Visualization
**Associative Memory**, exemplified by Hopfield Networks, relies on symmetric weights and an Energy function ($E$), with stable versions using Lyapunov functions. **Graph Neural Networks (GNNs)** handle graph data via permutation-equivariant message passing (e.g., MPNNs), employing GCNs and GATs to mitigate oversmoothing in NLP. **Radial Basis Function (RBF) Networks** function as universal approximators. Model interpretability is supported by **CAM** (derived via Global Average Pooling) and model-agnostic methods like Grad-CAM and Score-CAM, with optimization often guided by metrics such as mean-squared error using simulated annealing or genetic algorithms.
