# **Concise Summary**

## **Graph Neural Networks (GNNs)**
Graph Neural Networks are deep learning models designed to process graph-structured data, where nodes represent entities and edges represent relationships. The core architecture relies on **message passing layers**, which are permutation-equivariant and update node representations by aggregating information from immediate neighbors. This process increases the receptive field with each layer, allowing nodes to capture information from distant parts of the graph. Common variants include **Graph Convolutional Networks (GCNs)**, which use spectral filters and normalized adjacency matrices, and **Graph Attention Networks (GATs)**, which assign learnable weights to edges to focus on important neighbors.

To process entire graphs, GNNs utilize **pooling layers** that reduce the graph size. **Local pooling** downsamples the graph to increase the receptive field, while **global pooling** aggregates node features into a fixed-size representation. Despite their power, GNNs are theoretically limited by the Weisfeiler–Leman Graph Isomorphism Test, meaning they cannot distinguish between non-isomorphic graphs. Recent research also addresses **heterophily**, where nodes with different attributes are connected, challenging the traditional homophily assumption that underpins many GNN successes. Applications span protein folding (AlphaFold), social networks, combinatorial optimization, and anomaly detection.

## **Autoencoders and Variational Autoencoders**
**Autoencoders** are neural networks used for unsupervised learning, dimensionality reduction, and feature extraction. They consist of an **encoder** that compresses input data into a lower-dimensional latent space and a **decoder** that reconstructs the original data. Standard autoencoders are trained by minimizing the reconstruction error between the input and output, typically using Mean Squared Error. Variations like **Sparse Autoencoders** enforce sparsity in the latent space to improve interpretability, while **Denoising Autoencoders** learn robust representations by reconstructing corrupted inputs.

**Variational Autoencoders (VAEs)** extend this concept by introducing probabilistic elements. Instead of mapping inputs to fixed vectors, VAEs map them to probability distributions (parameters like mean and variance) in the latent space. This allows for the generation of new, diverse data samples by sampling from the learned latent distribution. The training of VAEs is governed by the **Evidence Lower Bound (ELBO)**, which balances reconstruction accuracy with a regularization term (Kullback–Leibler divergence) that ensures the latent distribution matches a prior. Recent advancements include statistical distance variants and hybrid models combining VAEs with Generative Adversarial Networks.

## **Transformers and Recurrent Neural Networks**
**Recurrent Neural Networks (RNNs)** are designed to handle sequential data by maintaining a hidden state that acts as memory. Variants like **Long Short-Term Memory (LSTM)** and **Gated Recurrent Units (GRU)** were developed to solve the vanishing gradient problem, enabling the modeling of long-term dependencies. While effective, RNNs process data sequentially, limiting parallelization. **Transformers** have largely superseded RNNs in many applications by utilizing **self-attention mechanisms** to weigh the importance of different tokens in a sequence simultaneously. This allows for parallel processing and efficient capture of long-range dependencies, though it introduces a quadratic computational cost relative to sequence length.

Transformers utilize **position encodings** to understand the order of tokens and **multi-head attention** to focus on different aspects of the input. Architectures like **Vision Transformers (ViT)** adapt this model to computer vision by treating images as sequences of patches. **Encoder-only** transformers (e.g., BERT) are used for tasks like text classification and question answering, while **decoder-only** models (e.g., GPT series) excel at text generation. Recent innovations include **FlashAttention** for efficient inference, **speculative decoding** to speed up generation, and **RoPE** for better handling of varying context lengths.

## **Generative Adversarial Networks (GANs)**
**Generative Adversarial Networks (GANs)** are a class of generative models composed of two neural networks engaged in a zero-sum game: a **generator** that creates synthetic data, and a **discriminator** that attempts to distinguish between real and generated data. The generator aims to fool the discriminator, while the discriminator aims to correctly identify real samples. This adversarial process drives the generator to learn the underlying data distribution.

Early GANs faced issues such as **mode collapse** (generating limited variety) and **vanishing gradients**. These were addressed by variants like **Wasserstein GANs (WGANs)**, which use the Wasserstein distance to provide more stable gradients, and **Conditional GANs**, which allow for controlled generation based on specific conditions. Advanced architectures like **StyleGAN** have been developed to generate high-fidelity images by decomposing style into latent vectors. Beyond image generation, GANs are used in scientific simulations, medical imaging for privacy-preserving data creation, and artistic applications.

## **Convolutional Neural Networks (CNNs)**
**Convolutional Neural Networks (CNNs)** are the standard architecture for image recognition and computer vision tasks. They exploit the spatial structure of data through **convolutional layers** that apply learnable filters to local regions of the input, followed by **pooling layers** that reduce dimensionality and provide translation invariance. Key features include **weight sharing**, which drastically reduces the number of parameters compared to fully connected networks, and **local connectivity**, which respects the spatial relationships in images.

CNNs are trained using backpropagation to minimize a loss function, often employing **ReLU** activation functions to introduce non-linearity and techniques like **Dropout** to prevent overfitting. The architecture has evolved from simple convolutional layers to complex stacks involving **depthwise separable convolutions**, **dilated convolutions** for expanding receptive fields, and **residual connections** to enable training of very deep networks. Applications range from object detection and facial recognition to drug discovery and video analysis, with CNNs serving as the foundation for many modern AI systems.
