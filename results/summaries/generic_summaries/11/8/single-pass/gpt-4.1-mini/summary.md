# Variational Autoencoder (VAE)

Variational autoencoders are generative models that utilize neural networks to perform amortized inference, optimizing a lower bound (ELBO) on data likelihood by approximating intractable posteriors with parameterized encoder networks. The architecture consists of an encoder mapping data to a latent space and a decoder reconstructing data from latent variables. Optimization balances reconstruction error and Kullback–Leibler divergence between approximate and true posteriors. The reparameterization trick enables gradient-based training despite stochastic sampling. Various VAE variants incorporate alternative statistical distances (e.g., Wasserstein, Maximum Mean Discrepancy) and modifications like β-VAE for disentangled representation, conditional VAEs for supervised factors, or extensions blending with GANs.

# Class Activation Mapping (CAM)

CAM methods provide visual explanations for CNN predictions by highlighting class-discriminative image regions. The original CAM requires architectural modifications including global average pooling (GAP) before the classifier, generating class-specific heatmaps from weighted sums of feature maps. Grad-CAM generalizes CAM by using gradients of class scores with respect to feature maps, enabling applicability to virtually any CNN architecture without retraining. Variants such as Guided Grad-CAM, Grad-CAM++, Score-CAM, and LayerCAM improve localization precision, handle multiple instances, or remove dependence on gradients, combining coarse localization with high-resolution saliency maps for interpretability and enhanced visualization.

# Graph Neural Network (GNN)

GNNs process graph-structured data through permutation-equivariant message passing layers that aggregate neighbor information iteratively, expanding each node’s receptive field. Common GNN architectures include Graph Convolutional Networks (GCN), which generalize spectral filters to graphs; Graph Attention Networks (GAT) that weigh neighbor contributions dynamically via attention; and Gated Graph Sequence Neural Networks (GGS-NNs) that integrate gating mechanisms like GRUs. Pooling layers (top-k, self-attention) coarsen graphs to capture hierarchical structure. Challenges such as oversmoothing and oversquashing arise with deep layers. GNNs apply widely in protein folding (AlphaFold), social networks, combinatorial optimization, cybersecurity, water distribution modeling, vision, and NLP, with recent work addressing heterophily in graphs.

# Vision Transformer (ViT)

The Vision Transformer adapts the Transformer architecture from NLP to images by splitting an image into fixed-size patches, embedding them with positional encodings, and processing them through stacked Transformer encoder layers employing multi-head self-attention. It overcomes CNNs' locality biases and captures long-range dependencies, achieving state-of-the-art results in image classification and related tasks. Variants enhance efficiency and robustness via hybrid CNN preprocessing, hierarchical attention (Swin Transformer), masked autoencoders for self-supervised learning, and self-distillation methods like DINO. ViTs differ from CNNs in inductive biases, requiring larger datasets but yielding improved long-range modeling and robustness. Applications span image classification, detection, segmentation, and image generation.

# Autoencoder

An autoencoder is a neural network architecture consisting of an encoder that maps input data to a typically lower-dimensional latent representation (code) and a decoder that reconstructs the input from this code. Training minimizes reconstruction loss to learn compressed, meaningful representations. Variants include variational autoencoders (probabilistic latent variables), sparse autoencoders (latent sparsity), denoising autoencoders (robustness via input corruption), contractive autoencoders (regularizing encoder sensitivity), and concrete autoencoders (discrete feature selection). Autoencoders facilitate dimensionality reduction, anomaly detection, image processing, and generative modeling. Deep, multi-layer encoders/decoders improve compression and feature learning beyond linear methods like PCA.

# Wasserstein GAN (WGAN)

Wasserstein GAN reformulates the original GAN framework by replacing the Jensen–Shannon divergence with the Wasserstein-1 (Earth Mover’s) distance as the metric between real and generated data distributions. This change leads to better gradient behavior for the generator, mitigating problems like mode collapse and vanishing gradients. The discriminator (or critic) is constrained to be Lipschitz continuous (e.g., via weight clipping, spectral normalization, or gradient penalties). WGAN training involves a zero-sum game where the critic estimates Wasserstein distance, guiding the generator to approximate the true data distribution. The approach improves training stability and convergence compared to standard GANs.

# Radial Basis Function (RBF) Network

An RBF network is a three-layer feedforward neural network with an input layer, a single hidden layer of neurons employing radially symmetric basis functions (typically Gaussian), and a linear output layer. Each hidden neuron computes a function of the Euclidean distance between the input and a center vector. The network output is a weighted sum of these basis functions, optionally normalized. RBF networks are universal approximators, capable of function interpolation and approximation. Training commonly proceeds by unsupervised selection of centers (e.g., clustering) followed by supervised optimisation of output weights via least squares or gradient descent. Applications include time series prediction and control of chaotic systems.

# Generative Adversarial Network (GAN)

A GAN consists of two neural networks—the generator and discriminator—that compete in a zero-sum game. The generator maps samples from a latent space to data space, aiming to produce realistic outputs; the discriminator estimates the probability that a sample is real or generated. Training proceeds by alternating optimization to improve both networks. GANs do not explicitly model probability densities, allowing efficient sampling but sometimes suffering from unstable convergence and mode collapse. Variants include conditional GANs, InfoGAN, BiGAN, and CycleGAN for specialized tasks and improved learning. GANs have broad applications in image generation, medical imaging, scientific simulation, and more, while also raising ethical concerns regarding generated fake content.

# Recurrent Neural Network (RNN)

RNNs are neural networks with loops allowing information persistence across sequence elements, enabling modeling of temporal or sequential data. Architectures include standard RNNs, LSTM (Long Short-Term Memory) networks addressing vanishing gradients via gating mechanisms, GRUs (Gated Recurrent Units), bidirectional and stacked variants. RNNs operate by maintaining hidden states updated at each step, enabling tasks like language modeling, speech recognition, time series forecasting, and sequence transduction with encoder-decoder configurations. Training involves specialized algorithms like Backpropagation Through Time and techniques like teacher forcing. Variants such as Echo State Networks and Neural Turing Machines extend capabilities to model memory and complex sequence processing.

# Transformer (Deep Learning)

Transformers are neural network architectures based on self-attention mechanisms that enable parallel processing of sequential data, overcoming the limitations of RNNs. Introduced in 2017, transformers consist of stacked layers with multi-head self-attention, positional encodings to retain sequence order, and feedforward networks augmented by residual connections and layer normalization. The architecture includes encoder and decoder modules, supporting autoregressive generation and sequence-to-sequence tasks. Transformers led to breakthroughs in NLP (e.g., BERT, GPT series) and have been adapted to vision, speech, protein folding, and multimodal tasks. Numerous improvements address efficiency, positional encoding, normalization, and large-scale training, including innovations like KV caching and FlashAttention.

# Hopfield Network

Hopfield networks are fully connected recurrent neural networks functioning as associative memory systems with binary or continuous neurons. Using symmetric weights trained typically by Hebbian or Storkey learning rules, the network dynamics minimize an energy (Lyapunov) function guaranteeing convergence to stable attractor states representing stored memories. Hopfield networks can recall stored patterns from partial or noisy inputs but suffer from spurious states and limited storage capacity. Modern Hopfield networks (dense associative memories) incorporate higher-order interactions and non-linearities to exponentially increase storage capacity and efficiency. Applications include optimization problems, models of human memory, and pattern completion.

# Convolutional Neural Network (CNN)

CNNs are deep neural networks designed to process data with grid-like topology, such as images, by exploiting spatial local correlations. Core components include convolutional layers with shared-weight filters applied over local receptive fields, non-linear activations (commonly ReLU), pooling layers for spatial downsampling and translation invariance, and fully connected layers for classification. CNN architectures incorporate hyperparameters such as filter size, stride, padding, and number of filters, optimized for the target data. Historically inspired by biological vision and developed since the 1980s, CNNs have revolutionized image recognition, video analysis, and related fields. Regularization techniques like dropout prevent overfitting. CNNs have been extended and integrated with other architectures for diverse applications including medical imaging, NLP, and game playing.
