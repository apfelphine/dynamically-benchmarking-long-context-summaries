# Summary

## Autoencoder

An autoencoder is a neural network framework composed of two functions: an encoder that compresses input data into a latent code space, and a decoder that reconstructs the original input from this compressed representation. Typically, the latent space has lower dimensionality than the input, enforcing compression and enabling dimensionality reduction. Training involves minimizing a reconstruction loss over a reference data distribution, often optimized via gradient descent. Variations such as Variational Autoencoders (VAEs) model latent spaces probabilistically to enable generative tasks, Sparse Autoencoders enforce latent sparsity to improve feature learning, Denoising Autoencoders reconstruct clean inputs from corrupted data, and Contractive Autoencoders penalize sensitivity to input perturbations. Other variants include Minimum Description Length Autoencoders, which optimize for efficiency and interpretability, and Concrete Autoencoders for discrete feature selection. Depth in autoencoders enhances representational power and compression quality. Historically rooted in extensions to PCA and nonlinear dimensionality reduction, autoencoders are widely used in dimensionality reduction, anomaly detection, information retrieval, image processing, drug discovery, and machine translation, often as components in larger AI systems.

## Graph Neural Networks (GNN)

GNNs operate on graph-structured data via permutation-equivariant layers, primarily implemented through message passing between nodes where each node aggregates information from its neighbors. Architectures include Graph Convolutional Networks (GCNs) that generalize CNNs to graphs, Graph Attention Networks (GATs) that weight neighbor contributions via attention mechanisms, and Gated Graph Sequence Neural Networks using gated recurrent units. Pooling layers (top-k and self-attention pooling) enable graph coarsening. GNNs have limitations tied to the Weisfeiler–Leman isomorphism test but extensions exist. Challenges include learning under heterophily (low homophily) where node connections are dissimilar. Applications span protein folding (e.g., AlphaFold), social networks, combinatorial optimization, cybersecurity, water distribution modeling, computer vision via graph-based image representation, and natural language processing for semantic understanding.

## Radial Basis Function Network (RBF)

RBF networks consist of an input layer, a hidden layer with neurons activated by radial basis functions (commonly Gaussian), and a linear output layer. Each hidden neuron is centered on a vector, and its output depends on the distance from input to center, providing local receptive fields. RBF networks are universal approximators capable of interpolating and approximating functions. Normalized variants weigh contributions to ensure probabilistic interpretations. Training typically involves unsupervised selection of centers (often via clustering) followed by supervised fitting of linear output weights, achievable via closed-form pseudoinverse or gradient descent. RBFs have been used for function approximation, chaotic time series prediction (e.g., logistic map), and control applications.

## Variational Autoencoder (VAE)

VAEs are generative probabilistic models combining neural encoders and decoders with latent variables governed by prior distributions. They optimize an evidence lower bound (ELBO) balancing reconstruction accuracy and the Kullback–Leibler divergence between the approximate posterior and the prior. The reparameterization trick enables gradient-based optimization by expressing latent variables as deterministic functions of noise and parameters. Extensions include β-VAE (improving latent disentanglement), Conditional VAEs (conditioning on labels), and hybrid models mixing VAEs with generative adversarial networks. Statistical distance-based variants replace KL divergence with alternative discrepancy measures (e.g., Wasserstein, Maximum Mean Discrepancy), enhancing training and sample quality.

## Recurrent Neural Network (RNN)

RNNs process sequential data by maintaining a hidden state updated at each time step, enabling learning of temporal dependencies. Architectures include standard RNNs, stacked (deep) RNNs, bidirectional RNNs processing sequences in both directions, and encoder-decoder configurations for sequence transduction tasks like machine translation. Variants address vanishing gradient problems: Long Short-Term Memory (LSTM) units and Gated Recurrent Units (GRU) incorporate gating mechanisms for better long-term memory retention. Other architectures include Hopfield networks (associative memory), Echo State Networks (reservoir computing), Neural Turing Machines (external memory coupling), and continuous-time RNNs modeled via differential equations. Training involves backpropagation through time and techniques like teacher forcing; global optimization methods such as genetic algorithms are also used. RNNs have wide applications in language modeling, speech recognition, handwriting recognition, anomaly detection, and time series prediction.

## Class Activation Mapping (CAM)

CAM techniques provide visual explanations for CNN decisions by highlighting regions of an input image contributing most to a predicted class. The original CAM requires a CNN architecture modified to use global average pooling (GAP) before classification and produces class-specific heatmaps by weighted sums of activation maps. Grad-CAM generalizes CAM by using gradients flowing into a convolutional layer to weight feature maps, enabling application to arbitrary CNNs without architectural changes. Variants such as Guided Grad-CAM, Grad-CAM++, Score-CAM, and Layer-CAM improve resolution, localization accuracy, or reduce reliance on gradients, enhancing interpretability and applicability.

## Hopfield Network

Hopfield networks are recurrent neural networks modeling associative memory with binary (or continuous) threshold units and symmetric connections governed by Hebbian learning rules. Their dynamics minimize an energy function guaranteeing convergence to stable attractor states representing stored memories. They can recover full patterns from partial or noisy inputs but suffer from storage capacity limitations and spurious attractor states. Modern Hopfield networks or Dense Associative Memories extend classical models by introducing higher-order interactions, enabling super-linear or exponential memory capacity and connections to contemporary attention mechanisms. Variants include hierarchical associative memory networks and continuous variable models. Training involves energy minimization; learning rules include standard Hebbian and the more efficient Storkey rule.

## Vision Transformer (ViT)

Vision Transformers adapt transformer architectures for image analysis by dividing images into fixed-size patches, embedding these patches, and processing them as token sequences through standard transformer encoders. Positional embeddings add spatial information. ViT overcomes CNN limitations in modeling long-range dependencies but requires large amounts of training data. Variants include masked autoencoders (MAE) for self-supervised learning, Swin Transformer with shifted windows for efficient local attention, and TimeSformer for video understanding. Architectural improvements include alternative pooling methods replacing classification tokens and positional encoding schemes like RoPE and ALiBi. ViTs have achieved state-of-the-art results in image classification, segmentation, and synthesis and have influenced CNN developments.

## Convolutional Neural Network (CNN)

CNNs are deep neural networks designed for grid-like data, notably images, featuring convolutional layers with local receptive fields and shared weights, pooling layers for spatial downsampling, and fully connected layers for classification. They exploit spatial locality and translation equivariance, reducing parameters compared to fully connected networks and enabling hierarchical feature learning. Historical inspirations include studies of receptive fields in the visual cortex and the neocognitron model. CNNs utilize layers such as ReLU activations and max pooling. Training is typically via backpropagation with dropout and data augmentation as regularization methods. Applications encompass image and video recognition, natural language processing, anomaly detection, drug discovery, and gameplay AI. They have been accelerated by GPU implementations and remain foundational in computer vision.

## Wasserstein Generative Adversarial Network (WGAN)

WGAN modifies the original GAN framework by replacing the Jensen–Shannon divergence with the Wasserstein (Earth Mover) distance as a measure of discrepancy between real and generated distributions. The discriminator (critic) is constrained to be Lipschitz continuous to satisfy Kantorovich-Rubenstein duality, providing smoother gradients that improve training stability and mitigate problems like mode collapse and vanishing gradients common in GANs. Methods to enforce Lipschitz constraints include weight clipping, spectral normalization, and gradient penalty. WGAN recasts the adversarial game to minimize the Wasserstein distance, leading to more meaningful loss values and better convergence behaviors in practice.

## Transformer (Deep Learning)

Transformers are neural network architectures featuring self-attention mechanisms allowing parallel processing of sequential data, overcoming limitations of recurrent models such as dependency on previous states and difficulty in long-range dependency modeling. Introduced in 2017 ("Attention Is All You Need"), transformers use tokenization, positional encoding, multi-head scaled dot-product attention, feedforward layers, residual connections, and layer normalization. The architecture includes encoder and decoder stacks enabling sequence-to-sequence modeling. Training stability techniques include learning rate warmup and LayerNorm placement. Variants adapt the architecture for tasks including masked language modeling, autoregressive generation, and multimodal learning. Transformers have enabled breakthroughs in NLP (e.g., BERT, GPT series), computer vision (e.g., ViT), and beyond. Efficiency improvements address quadratic scaling via sparse or approximated attention methods. Transformers have become the backbone of large language models and diverse AI systems.
