## Autoencoder Summary

An autoencoder is a neural network composed of an encoder family ($E_{\phi}$) and a decoder family ($D_{\theta}$). The encoder maps an input message ($x$) from the input space ($\mathcal{X}$) to a code ($z$) in a latent space ($\mathcal{Z}$), while the decoder reconstructs the message ($\text{x}'$) from the code. The goal of training is to minimize a loss function, $L(\theta, \phi) = \mathbb{E}_{x\sim \mu_{ref}}[d(x, D_{\theta}(E_{\phi}(x)))]$, where $\mu_{ref}$ is the reference distribution and $d$ is a reconstruction quality function. An autoencoder is considered undercomplete when the code space ($\mathcal{Z}$) is smaller than the message space ($\mathcal{X}$), allowing it to compress the message, and it can be used to generate messages indistinguishable from real ones by feeding arbitrary codes ($z$) to the decoder.

Variations of the autoencoder include the **Denoising Autoencoder (DAE)**, which recovers original messages from noisy inputs during training. The **Contractive Autoencoder (CAE)** incorporates a contractive regularization loss to ensure that small input variations result in small variations in the code. The **Minimum Description Length Autoencoder (MDL-AE)** minimizes the total description length, balancing code size ($L_{\text{code}}$) and reconstruction error ($L_{\text{error}}$). The **Variational Autoencoder (VAE)** is a generative model where the latent space is a mixture of distributions, trained by optimizing the Evidence Lower Bound (ELBO) using techniques like the reparameterization trick.
