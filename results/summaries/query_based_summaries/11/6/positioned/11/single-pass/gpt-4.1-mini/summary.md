# Summary: Autoencoder

An **autoencoder** is a neural network architecture designed to learn compressed latent representations of input data by coupling an encoder function \(E_{\phi} : \mathcal{X} \to \mathcal{Z}\) and a decoder function \(D_{\theta} : \mathcal{Z} \to \mathcal{X}\), typically with \(\dim(\mathcal{Z}) < \dim(\mathcal{X})\). The encoder maps inputs to a lower-dimensional code, and the decoder reconstructs the input from this code. Training involves minimizing a reconstruction loss, often mean squared error, over a reference data distribution. This process can be seen as dimensionality reduction and feature extraction, where the quality of compression and reconstruction is optimized via techniques like gradient descent.

Variations of autoencoders introduce additional constraints or modifications to the architecture or loss to encourage properties like sparsity (Sparse Autoencoder), robustness to noise (Denoising Autoencoder), contractive mapping (Contractive Autoencoder), or probabilistic modeling of latent space (Variational Autoencoder). Notably, Variational Autoencoders (VAEs) model the latent space as distributions instead of fixed vectors, optimizing the Evidence Lower Bound (ELBO) to balance reconstruction accuracy and latent regularization. Autoencoders have broad applications including dimensionality reduction, anomaly detection, information retrieval, image processing (denoising, compression), machine translation, and domain-specific tasks such as drug discovery and communication system design.
