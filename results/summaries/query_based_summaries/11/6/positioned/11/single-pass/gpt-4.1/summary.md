## Autoencoder: Concise Summary

An **autoencoder** is a neural network model consisting of two primary functions: an encoder (`E_φ`) that maps input data to a lower-dimensional latent representation, and a decoder (`D_θ`) that reconstructs the input from this latent space. The model is trained to minimize a loss function that measures the difference between original data and its reconstruction (typically using mean squared error for empirical datasets), thereby learning a compressed, often undercomplete, representation of the data. Both encoder and decoder are usually implemented as multilayer perceptrons, and training is generally performed via gradient descent over the reconstruction loss.

Autoencoders have numerous variations, including sparse autoencoders (which enforce sparsity in the latent space), denoising autoencoders (trained to reconstruct clean inputs from corrupted ones), contractive autoencoders (with regularization that penalizes sensitivity to input perturbation), minimum description length autoencoders, and concrete autoencoders for discrete feature selection. They are foundational components for tasks such as dimensionality reduction, information retrieval, anomaly detection, image processing (compression and denoising), and as building blocks for more complex models like variational autoencoders (VAEs). Autoencoders have a rich history, seeing early applications in the 1980s and evolving into crucial tools for deep learning in the 21st century.
