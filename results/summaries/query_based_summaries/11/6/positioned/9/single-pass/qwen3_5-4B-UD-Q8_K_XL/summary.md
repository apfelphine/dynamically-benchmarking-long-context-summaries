An **autoencoder** is a neural network architecture designed to learn a compressed representation of data by encoding input information into a latent vector and then decoding it back to the original space. It consists of two primary components: an **encoder** that maps the input from a high-dimensional space to a lower-dimensional latent space (compression), and a **decoder** that reconstructs the input from this latent representation. The goal of training an autoencoder is to minimize the reconstruction error (loss) between the original input and the reconstructed output, typically using techniques like gradient descent and L2 loss. A defining characteristic of standard autoencoders is the use of an **undercomplete** architecture, where the latent space has fewer dimensions than the input space, forcing the model to learn non-linear mappings that capture essential features rather than simply copying the signal.

Various specialized variations of autoencoders exist to address specific challenges such as sparsity, noise, or regularization. **Sparse autoencoders** enforce sparsity in the latent codes to improve feature selectivity, while **denoising autoencoders** train on corrupted inputs to learn robust representations by reconstructing clean data. **Variational autoencoders (VAEs)** introduce a probabilistic framework where the encoder outputs parameters for a distribution (mean and variance) rather than a fixed point, enabling the generation of new, diverse data samples by sampling from the latent space. Other variants include **contractive autoencoders**, which add regularization to make the latent representation insensitive to small input perturbations, and **minimum description length autoencoders**, which optimize for information-theoretic efficiency. Despite the existence of more effective architectures like transformers, autoencoders remain foundational for tasks such as dimensionality reduction, anomaly detection, image denoising, and unsupervised feature learning.
