Based strictly on the provided text, an **Autoencoder** is a neural network architecture defined by two complementary families of functions: an encoder that maps input messages from a high-dimensional space $\mathcal{X}$ to a lower-dimensional latent code space $\mathcal{Z}$, and a decoder that reconstructs the original message from that code. The primary objective is to minimize a reconstruction loss function, typically the mean squared error between the input and the reconstructed output, thereby performing dimensionality reduction or learning compact representations. While standard autoencoders use multilayer perceptrons, variations exist to enhance specific capabilities: **Variational Autoencoders (VAEs)** introduce a probabilistic framework using a prior distribution and the Evidence Lower Bound (ELBO) to generate diverse samples; **Denoising Autoencoders (DAEs)** improve robustness by training on corrupted inputs; **Sparse Autoencoders (SAEs)** enforce sparsity in the latent space to improve classification; and **Contractive Autoencoders (CAEs)** add regularization to make learned features robust to infinitesimal input perturbations. Deep architectures are preferred as they can exponentially reduce computational costs and learning data requirements, and their weights are often related to Principal Component Analysis (PCA) when using linear activations.

Historically, autoencoders originated in the 1980s with concepts like "auto-association mode" and were later formalized through generalizations of PCA by Baldi and Hornik and Kramer. Their most significant modern development occurred in 2006 with Geoffrey Hinton's work on deep belief networks, which utilized Restricted Boltzmann Machines to pretrain deep autoencoders before fine-tuning them with backpropagation. Since then, autoencoders have been extensively applied to tasks such as dimensionality reduction, anomaly detection (by identifying high reconstruction error), image processing (including compression and denoising), and drug discovery. Recent applications include using Variational Autoencoders in generative models like Stable Diffusion and DALL-E, where they serve as components for image generation and representation learning.
