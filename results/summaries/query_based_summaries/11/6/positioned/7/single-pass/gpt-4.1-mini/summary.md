# Summary of Autoencoder

An **autoencoder** is a neural network architecture consisting of two components: an encoder \( E_{\phi} \) that maps input data \( x \in \mathcal{X} \) to a typically lower-dimensional latent code \( z \in \mathcal{Z} \), and a decoder \( D_{\theta} \) that reconstructs the data from the code. The parameters \( \theta, \phi \) are trained to minimize a reconstruction loss that measures the difference between the original data and its reconstruction \( D_{\theta}(E_{\phi}(x)) \), often using least squares over an empirical dataset. The latent space is usually lower dimensional (undercomplete) to encourage meaningful compression and feature extraction. Variations include overcomplete and sparse autoencoders, denoising autoencoders that reconstruct from corrupted inputs, and contractive autoencoders adding regularization via the Jacobian norm.

**Variational autoencoders (VAEs)** extend this by treating the latent code probabilistically, modeling an approximate posterior \( q_{\phi}(z|x) \) to the true posterior \( p_{\theta}(z|x) \) and optimizing the evidence lower bound (ELBO). This combines reconstruction error with a KL divergence regularizer pushing latent codes towards a prior distribution (usually Gaussian). The reparameterization trick allows backpropagation through stochastic encoders. VAEs are generative models that can map latent samples back to the data space. Various advanced forms use alternative divergences or combine properties from GANs.

Autoencoders have important applications in dimensionality reduction (sometimes outperforming PCA), anomaly detection (relying on reconstruction error), image processing (compression, denoising, super-resolution), and representation learning for downstream tasks. Deep autoencoders with multiple layers can capture hierarchical latent structures, improving compression and data modeling. Variants such as sparse and denoising autoencoders encode inductive biases to learn robust, interpretable features. They also serve as components in larger architectures like masked autoencoders for self-supervised learning in vision and natural language.
