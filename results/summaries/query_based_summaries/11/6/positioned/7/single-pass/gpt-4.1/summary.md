## Autoencoder

An **autoencoder** is a neural network architecture composed of two main parts: an encoder and a decoder. The encoder maps input data (from a high-dimensional space) to a low-dimensional latent code, while the decoder reconstructs the data from this code. Typically, both encoder and decoder are implemented as multilayer perceptrons. Training an autoencoder involves minimizing a reconstruction loss, which measures how closely the decoder’s output matches the original input—commonly using mean squared error or L2 loss. Autoencoders are often undercomplete, meaning the latent space has fewer dimensions than the input, encouraging the network to learn compressed representations.

There are numerous variations, including **Variational Autoencoders (VAEs)**, which use probabilistic latent spaces and optimize a combination of reconstruction loss and Kullback–Leibler divergence; **Sparse Autoencoders**, which enforce sparsity in the latent codes; **Denoising Autoencoders**, trained to reconstruct input from deliberately corrupted versions; and **Contractive Autoencoders**, which regularize the encoder to be insensitive to minor input variations. Autoencoders have applications in dimensionality reduction, anomaly detection, information retrieval, image processing, and as foundational modules in generative models and machine translation systems. Their history traces back to connections with Principal Component Analysis and their widespread use for unsupervised feature learning and data modeling.
