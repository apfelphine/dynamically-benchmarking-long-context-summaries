An Autoencoder is defined by two components: an encoder family, $E_{\phi}: \mathcal{X} \rightarrow \mathcal{Z}$, and a decoder family, $D_{\theta}: \mathcal{Z} \rightarrow \mathcal{X}$. The encoder maps an input message $x$ from the message space $\mathcal{X}$ to a code $z$ in the code space $\mathcal{Z}$, while the decoder reconstructs a message $x'$ from the code $z$. Both are typically implemented as multilayer perceptrons (MLPs).

Training an autoencoder involves minimizing a loss function, $L(\theta, \phi) = \mathbb{E}_{x\sim \mu_{\text{ref}}}[d(x, D_{\theta}(E_{\phi}(x)))]$, where $\mu_{\text{ref}}$ is a reference probability distribution and $d$ is a reconstruction quality function. An undercomplete autoencoder, where $\mathcal{Z}$ has fewer dimensions than $\mathcal{X}$, functions as a compressor. In an ideal scenario, an undercomplete autoencoder can generate new messages indistinguishable from real ones by feeding the decoder arbitrary codes $z$.

Variations include:
*   **Variational Autoencoders (VAEs):** These model the latent space as a mixture of distributions, optimizing a lower bound of the data likelihood (ELBO).
*   **Sparse Autoencoders (SAE):** These enforce sparsity on the latent codes to improve performance on classification tasks.
*   **Denoising Autoencoders (DAE):** These are trained by intentionally corrupting the inputs to force the network to recover the original message without noise.
*   **Contractive Autoencoders (CAE):** These add a regularization loss based on the Frobenius norm of the encoder's Jacobian matrix to ensure small input variations lead to small code variations.
*   **Minimum Description Length Autoencoders (MDL-AE):** These leverage information theory to minimize the combined length of the compressed code and the reconstruction error.
