# Summary of Autoencoder

An **autoencoder** is a neural network architecture comprising two parametrized functions: an **encoder** that maps input data \(x \in \mathcal{X}\) to a compressed latent code \(z \in \mathcal{Z}\), and a **decoder** that reconstructs the input from the code. Typically, \(\mathcal{X} = \mathbb{R}^m\) and \(\mathcal{Z} = \mathbb{R}^n\) with \(n < m\), enforcing compression. Autoencoders are trained by minimizing a reconstruction loss \(L(\theta,\phi) = \mathbb{E}_{x \sim \mu_{ref}} [d(x, D_\theta(E_\phi(x)))]\), often using L2 loss over a dataset, via gradient descent. Their goal is to learn efficient low-dimensional representations that retain essential information, enabling tasks like dimensionality reduction and data generation.

Variations include **variational autoencoders (VAEs)** which introduce a probabilistic latent space, **sparse autoencoders (SAEs)** encouraging sparsity in codes, **denoising autoencoders (DAEs)** trained to reconstruct clean data from corrupted inputs, and **contractive autoencoders (CAEs)** that add a Jacobian norm penalty for robustness. Deep autoencoders with multiple encoding and decoding layers provide superior compression and learning capabilities, often pretrained via deep belief networks. Applications span **dimensionality reduction**, outperforming PCA in nonlinear settings; **anomaly detection**, by identifying inputs that reconstruct poorly; **image denoising and compression**; **information retrieval** via semantic hashing; and extensions to domains such as **drug discovery** and **machine translation**.
