An autoencoder is a neural network that learns to compress and reconstruct input data by mapping it to a lower-dimensional latent space and then reconstructing the original input. It consists of an encoder that maps the input to a latent representation and a decoder that reconstructs the input from the latent code. The quality of reconstruction is measured by a loss function, typically the mean squared error, and the model is trained to minimize this loss. Autoencoders can be undercomplete (with fewer latent dimensions than input) to achieve dimensionality reduction or overcomplete (with more latent dimensions) to learn identity mappings. Variants include sparse autoencoders, which encourage sparse latent codes; denoising autoencoders, which reconstruct data from corrupted inputs; contractive autoencoders, which promote stability to small input changes; and variational autoencoders, which use probabilistic modeling to generate data. Autoencoders are widely used for dimensionality reduction, information retrieval, anomaly detection, image processing, and feature learning. Deep autoencoders offer advantages in compression and performance over shallow ones.
