An **autoencoder** is a neural network architecture consisting of an encoder and a decoder, designed to learn a compressed representation (latent code) of input data and reconstruct it. It is trained to minimize the reconstruction error between the original input and the output of the decoder. The encoder maps input data to a lower-dimensional latent space, while the decoder reconstructs the original input from this latent representation. 

Autoencoders are primarily used for dimensionality reduction, feature learning, and information retrieval. Variants such as **variational autoencoders (VAEs)** introduce probabilistic modeling by learning a latent distribution, enabling generative capabilities. Other variants include **sparse autoencoders**, which promote sparsity in the latent representation, and **denoising autoencoders**, which learn to reconstruct clean data from noisy inputs. These models are also applied in anomaly detection, image processing, drug discovery, and natural language processing tasks.
