# Summary of Wasserstein GAN (WGAN)

Wasserstein GAN reformulates the original GAN framework by replacing the Jensen-Shannon divergence (used in the discriminator's objective) with the Wasserstein distance (Earth Mover’s distance) as a measure of difference between the generator's distribution and the reference data distribution. Defined over a metric probability space, WGAN models the discriminator (also called the critic) as a function with bounded Lipschitz norm, and the game objective becomes the expected difference between the critic’s outputs on generated versus real data samples. By Kantorovich-Rubenstein duality, the optimal discriminator strategy achieves this Wasserstein distance scaled by a constant, resulting in better gradients for the generator during training, which addresses issues like vanishing gradient and mode collapse inherent in original GANs.

Training WGANs involves maintaining the Lipschitz constraint on the discriminator, which can be done through several methods: weight clipping (bounding each discriminator layer’s weights within a fixed range), spectral normalization (controlling the spectral norm of weight matrices), or adding a gradient penalty that encourages discriminator gradients to have norm close to a target value. Compared to original GANs, WGANs provide more stable and meaningful learning signals to the generator, facilitating convergence and reducing common failure modes. Empirically, WGANs have demonstrated robustness against mode collapse, making them a significant improvement in generative adversarial training.
