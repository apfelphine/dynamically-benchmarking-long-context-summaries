Wasserstein GAN (WGAN) modifies the original GAN game, which is a zero-sum game involving a generator ($\mu_G$) and a discriminator ($D$), to address issues like vanishing gradients. The original GAN objective relies on the Jensen-Shannon divergence, and at equilibrium, the discriminator often outputs a constant value of $1/2$, providing little learning signal to the generator.

WGAN replaces the discriminator's strategy set with measurable functions $D:\Omega \to \mathbb{R}$ constrained by a bounded Lipschitz norm ($\|D\|_L \le K$). The WGAN objective function is defined as $L_{WGAN}(\mu_G, D) = \mathbb{E}_{x\sim \mu_G}[D(x)] - \mathbb{E}_{x\sim \mu_{ref}}[D(x)]$. By leveraging the Kantorovich-Rubenstein duality, the discriminator acts as a critic that guides the generator to minimize the Earth Mover's Distance ($W_1$) between its distribution ($\mu_G$) and the reference distribution ($\mu_{ref}$). This change allows the generator to receive a better gradient, mitigating the vanishing gradient problem common in the original GAN setup.
