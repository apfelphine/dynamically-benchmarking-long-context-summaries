Wasserstein GAN (WGAN) modifies the standard Generative Adversarial Network (GAN) game by replacing the divergence measure with the Wasserstein metric. The original GAN game's optimal discriminator computes the Jensen–Shannon divergence, and at equilibrium, the discriminator outputs a constant value of $1/2$. However, in high-dimensional settings like image generation, this can lead to the Jensen-Shannon divergence becoming infinite, resulting in a vanishing gradient problem for the generator.

WGAN addresses this by changing the discriminator's strategy set to be measurable functions with a bounded Lipschitz norm ($\|D\|_{L}\leq K$), and redefining the objective function as $L_{WGAN}(\mu _{G},D):=\mathbb {E} _{x\sim \mu _{G}}[D(x)]-\mathbb {E} _{x\sim \mu _{ref}}[D(x)]$. This change allows the discriminator to function as a critic providing a meaningful gradient that pushes the generator to minimize the $W_{1}$ distance between its distribution ($\mu_G$) and the reference distribution ($\mu_{ref}$), thus offering a better gradient signal than the original GAN objective.
