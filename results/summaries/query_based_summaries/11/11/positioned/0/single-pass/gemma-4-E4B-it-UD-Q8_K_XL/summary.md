## Wasserstein GAN Summary

The Wasserstein GAN (WGAN) addresses limitations found in the original GAN by utilizing the **Wasserstein metric** instead of divergence criteria like the Jensen-Shannon divergence. This metric is derived from the **Kantorovich-Rubenstein duality**, which states that for a metric space $\Omega$, the Wasserstein-1 distance $W_1(\mu, \nu)$ can be expressed as:
$$W_{1}(\mu ,\nu )={\frac {1}{K}}\sup _{\|f\|_{L}\leq K}\mathbb {E} _{x\sim \mu }[f(x)]-\mathbb {E} _{y\sim \nu }[f(y)]$$
In the WGAN game, the generator aims to minimize the objective $L_{WGAN}(\mu _{G},D):=\mathbb {E} _{x\sim \mu _{G}}[D(x)]-\mathbb {E} _{x\sim \mu _{ref}}[D(x)]$, while the discriminator (or "critic") aims to maximize it. The discriminator's strategy set is restricted to measurable functions $D:\Omega \to \mathbb{R}$ with a bounded Lipschitz norm ($\|D\|_{L}\leq K$). When the discriminator is effective, the generator is pushed to minimize $W_{1}(\mu _{G},\mu _{ref})$.

WGAN provides a better gradient than the original GAN because the optimal Wasserstein critic $D_{WGAN}$ has a gradient of 1 almost everywhere, unlike the $\ln(1-D(x))$ gradient in GANs, which can be flat in the middle, leading to larger variance in the GAN estimator. To train the discriminator while maintaining the bounded Lipschitz norm, several methods exist: **weight clipping** (clipping matrix entries to $[-c,c]$), **spectral normalization** (reassigning weights $W_i \leftarrow W_i/\|W_i\|_s$), or **gradient penalty** (adding a term $\mathbb {E} _{x\sim {\hat {\mu }}}[(\|\nabla D(x)\|_{2}-a)^{2}]$ to the loss). WGAN is claimed to solve the mode collapse problem.
