Wasserstein GAN (WGAN) modifies the standard GAN game by replacing the objective function based on the Jensen-Shannon divergence with the **Wasserstein metric**.

The WGAN game is defined over a metric space and involves two players: a generator ($\mu_G$) and a discriminator (critic, $D$). The discriminator's strategy set is restricted to measurable functions with a **bounded Lipschitz-norm** ($\|D\|_L \leq K$), and the objective function is $L_{WGAN}(\mu_G, D) := \mathbb{E}_{x\sim \mu_G}[D(x)] - \mathbb{E}_{x\sim \mu_{ref}}[D(x)]$. According to the Kantorovich-Rubenstein duality, the optimal discriminator's value is proportional to the $W_1$ distance between the generator and reference distributions. This formulation allows the generator to be consistently pushed toward minimizing the $W_1(\mu_G, \mu_{ref})$, providing a better gradient signal than the original GAN and addressing the vanishing gradient problem often encountered in GAN training.
