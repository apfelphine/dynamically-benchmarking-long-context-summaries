**Wasserstein GAN (WGAN)** is a variant of the original Generative Adversarial Network (GAN) designed to improve training stability and alleviate issues like mode collapse and vanishing gradients common in GANs. While traditional GANs formulate the generator-discriminator interaction as a zero-sum game minimizing the Jensen–Shannon divergence, WGAN replaces this with the Wasserstein-1 (Earth Mover's) distance, which better measures the "distance" between the generated and real data distributions.

WGAN leverages the Kantorovich-Rubinstein duality, defining the discriminator (termed "critic") as a function with bounded Lipschitz norm acting on a metric space. The objective function is the difference in expected critic outputs over generated and real samples. The generator aims to minimize this Wasserstein distance, pushing its distribution closer to the reference data distribution. Training the critic requires enforcing the Lipschitz constraint, done via methods like weight clipping, spectral normalization, or gradient penalty. Compared to traditional GANs, WGAN provides smoother gradients and more meaningful feedback to the generator, facilitating more stable convergence and reduced training difficulties in high-dimensional, complex data settings.
