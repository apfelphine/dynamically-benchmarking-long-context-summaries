## Wasserstein GAN Summary

The Wasserstein GAN (WGAN) is a variant of Generative Adversarial Networks (GANs) that utilizes the Wasserstein metric to address issues present in the original GAN formulation. While the standard GAN game's discriminator learns the Jensen–Shannon divergence, WGAN employs the Wasserstein metric, which is efficient to compute via the Kantorovich-Rubenstein duality. This duality defines the WGAN game where the discriminator, or "critic," must be a measurable function with a bounded Lipschitz norm ($\|D\|_{L}\leq K$), and the objective function is $L_{WGAN}(\mu _{G},D):=\mathbb {E} _{x\sim \mu _{G}}[D(x)]-\mathbb {E} _{x\sim \mu _{ref}}[D(x)]$.

The implementation of WGAN involves specific training methods to enforce the Lipschitz constraint on the discriminator. These methods include upper-bounding the norm by using activation functions like $\tanh$ whose derivative is bounded, weight clipping, spectral normalization, or using a gradient penalty term. A key advantage of WGAN is that its discriminator provides a more stable gradient to the generator compared to the standard GAN, which helps mitigate the problem of vanishing gradients when the generator distribution is disjoint from the reference distribution.
