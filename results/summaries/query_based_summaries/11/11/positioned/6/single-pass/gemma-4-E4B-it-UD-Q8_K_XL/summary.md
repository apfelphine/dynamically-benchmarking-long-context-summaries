Wasserstein GAN (WGAN) modifies the original Generative Adversarial Network (GAN) game to address issues like vanishing gradients. In the standard GAN game, the objective relies on the Jensen-Shannon divergence, which can lead to infinite divergence and zero learning signal when the generator's distribution is disjoint from the reference distribution, a common occurrence in high-dimensional spaces like images.

WGAN replaces this divergence criterion with the Wasserstein metric. This metric is computable efficiently through the Kantorovich-Rubenstein duality, which defines the Wasserstein distance ($W_1$) as a supremum over functions with a bounded Lipschitz norm ($K$). The WGAN objective function is then defined as $L_{WGAN}(\mu_G, D) = \mathbb{E}_{x \sim \mu_G}[D(x)] - \mathbb{E}_{x \sim \mu_{\text{ref}}}[D(x)]$. The discriminator (referred to as a "critic") is constrained to have a Lipschitz norm bounded by $K$. This modification provides a better gradient for the generator, which is motivated to minimize the Wasserstein distance $W_1(\mu_G, \mu_{\text{ref}})$, pushing the generator towards matching the reference distribution ($\mu_G = \mu_{\text{ref}}$).
