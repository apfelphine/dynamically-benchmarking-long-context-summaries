**Wasserstein GAN (WGAN)** is a modification of the standard Generative Adversarial Network (GAN) designed to address issues like vanishing gradients, which can occur when the generator's distribution ($\mu_G$) is disjoint from the reference distribution ($\mu_{ref}$) in high-dimensional spaces (e.g., ImageNet).

Instead of using the Jensen-Shannon divergence as its objective, WGAN utilizes the **Wasserstein metric** (or Earth Mover's distance). The WGAN game objective function is defined as $L_{WGAN}(\mu_G, D) := \mathbb{E}_{x\sim \mu_G}[D(x)] - \mathbb{E}_{x\sim \mu_{ref}}[D(x)]$. The discriminator (referred to as the "critic") must be constrained to have a bounded Lipschitz norm ($\|D\|_L \leq K$). The WGAN provides a better gradient signal to the generator compared to the original GAN because the Wasserstein metric is continuous even when distributions are disjoint. Training methods to enforce the Lipschitz constraint include weight clipping, spectral normalization, and gradient penalty.
