**Wasserstein GAN (WGAN)** is a modification of the original Generative Adversarial Network (GAN) that replaces the standard GAN objective function with the **Wasserstein metric** (or Earth Mover's distance).

The WGAN game is defined as a zero-sum game involving a generator ($\mu_G$) and a discriminator, which is renamed a "critic." Instead of using the Jensen–Shannon divergence, the WGAN uses the Kantorovich-Rubenstein duality. The objective function becomes $L_{WGAN}(\mu_G, D):=\mathbb{E} _{x\sim \mu _{G}}[D(x)]-\mathbb{E} _{x\sim \mu _{ref}}[D(x)]$. The discriminator's strategy set is restricted to measurable functions $D:\Omega \to \mathbb{R}$ with a bounded Lipschitz norm ($\|D\|_{L}\leq K$). This change provides the generator with a better, more stable gradient feedback compared to standard GANs, helping to mitigate problems like vanishing gradients.

Training WGANs requires different approaches for the discriminator to enforce the bounded Lipschitz norm. Methods include **weight clipping** (clamping all weights $W$ to $[-c, c]$) or **spectral normalization** (reassigning weights $W_i \leftarrow W_i / \|W_i\|_s$ after each discriminator update). An alternative approach is the **gradient penalty**, where a term $\mathbb{E} _{x\sim \hat{\mu}}[(\|\nabla D(x)\|_{2}-a)^{2}]$ is added to the discriminator's loss to enforce the Lipschitz constraint.
