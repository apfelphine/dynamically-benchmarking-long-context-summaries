**Generative Adversarial Network (GAN)**

A Generative Adversarial Network (GAN) is structured as a zero-sum game between two players: a generator ($\mu_G$) and a discriminator ($\mu_D$). The generator's objective is to produce samples ($\mu_G$) that closely mimic a reference distribution ($\mu_{ref}$), while the discriminator aims to distinguish between samples from $\mu_{ref}$ (which it should score near 1) and samples from $\mu_G$ (which it should score near 0). In practice, the generator maps from an easily sampled latent space ($\mu_Z$) to the output space ($\mu_G = \mu_Z \circ G^{-1}$), and the discriminator is typically a neural network function ($D$).

The original GAN objective function leads to the discriminator ideally calculating the Jensen-Shannon divergence between the two distributions. However, this can suffer from unstable convergence, mode collapse (where the generator fails to capture all modes of the input data), or vanishing gradients if the discriminator becomes too effective. To address these issues, variants exist: the **Wasserstein GAN (WGAN)** replaces the objective with the Wasserstein metric, which provides better gradients, while **Conditional GANs (cGANs)** allow the generator to create samples based on auxiliary information (like class labels). Other notable variants include **BigGAN** for large-scale image generation and **StyleGAN** architectures, which use progressive growth mechanisms for stable training at high resolutions.
