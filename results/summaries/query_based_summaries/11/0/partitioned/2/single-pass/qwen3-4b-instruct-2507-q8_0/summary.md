A **Generative Adversarial Network (GAN)** is a framework where a generator and a discriminator compete in a zero-sum game to produce realistic data. The generator creates data samples, aiming to fool the discriminator, while the discriminator learns to distinguish real data from generated samples. The game is defined by the objective function $L(G, D) = \mathbb{E}_{x \sim \mu_{\text{ref}}}[\ln D(x)] + \mathbb{E}_{z \sim \mu_Z}[\ln(1 - D(G(z)))]$, with the generator minimizing and discriminator maximizing this loss.

Key variants include:
- **Wasserstein GAN (WGAN)**: Uses the Wasserstein distance instead of Jensen-Shannon divergence, providing smoother gradients and better training stability. It restricts the discriminator to functions with bounded Lipschitz norm and uses a modified objective $L_{WGAN}(\mu_G, D) = \mathbb{E}_{x \sim \mu_G}[D(x)] - \mathbb{E}_{x \sim \mu_{\text{ref}}}[D(x)]$, which helps avoid mode collapse and improves convergence.
- **Conditional GANs**: Allow generation of data conditioned on labels, e.g., generating a cat image given a "cat" label.
- **Variants with alternative objectives**: Include Hinge loss, Least squares GAN, and others that modify the loss function to improve training stability and convergence.
- **Large-scale and scalable GANs**: Models like **BigGAN** use large-scale architectures (up to 80M parameters) to generate high-resolution images, while **StyleGAN** series introduce style mixing and progressive growth to enhance control and realism.
- **Invertible data augmentation**: Ensures training data augmentation does not bias the generator by using invertible transformations (e.g., rotations or Gaussian noise) that preserve data distribution, improving generalization.

Applications span image generation, medical imaging, art, and scientific simulations. GANs are used for image synthesis, face reconstruction, anomaly detection, and even modeling physical phenomena like gravitational lensing. Despite challenges like mode collapse and training instability, GANs have become foundational in generative modeling, with ongoing research improving stability, diversity, and interpretability.
