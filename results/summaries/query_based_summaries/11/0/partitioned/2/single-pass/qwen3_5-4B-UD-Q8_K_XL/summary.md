Based strictly on the provided text, a **Generative Adversarial Network (GAN)** is an implicit generative model defined as a zero-sum game between two neural networks: a **generator** and a **discriminator**. The generator maps a random noise vector from a latent space (e.g., a normal distribution) to data samples, aiming to produce a distribution that mimics a reference dataset. The discriminator attempts to distinguish between real data from the reference distribution and fake data generated by the generator. Theoretically, the game seeks a Nash equilibrium where the generator perfectly mimics the reference distribution, and the discriminator outputs a constant value of 0.5 for all inputs, indicating it cannot distinguish between real and generated samples.

The text details several **variants** designed to address specific challenges. **Wasserstein GANs (WGAN)** modify the game by restricting the discriminator to functions with bounded Lipschitz norms, utilizing the Wasserstein metric to solve issues like vanishing gradients and mode collapse. **Conditional GANs (cGANs)** allow the generator to condition outputs on additional labels, enabling tasks like generating specific image classes. Other variants include **Adversarial Autoencoders** (focusing on latent space structure), **InfoGAN** (using variational mutual information maximization to ensure informative latent codes), and **CycleGAN** (translating between unpaired domains). Large-scale versions like **BigGAN** utilize self-attention and deep architectures, while **StyleGAN** employs progressive growth and style mixing for high-quality image synthesis. Training stability is often improved through techniques like **invertible data augmentation** and the **Two Time-Scale Update Rule (TTUR)**, though challenges such as **mode collapse** (generating limited variety) and **vanishing gradients** remain significant. Evaluation typically relies on metrics like the **Inception Score (IS)** and **Fréchet Inception Distance (FID)**.
