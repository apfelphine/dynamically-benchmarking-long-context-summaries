**Generative adversarial networks (GANs)** are a class of generative models based on a zero-sum game between two neural networks: a generator and a discriminator. The generator's objective is to create synthetic data samples that approximate a reference distribution, while the discriminator aims to distinguish between real data from the reference set and the synthetic data produced by the generator. This adversarial training process forces the generator to improve its samples to fool the discriminator, theoretically converging to a state where the generator's output distribution matches the reference distribution.

Several variants of GANs have been developed to address specific challenges such as mode collapse, vanishing gradients, and training instability. The **Wasserstein GAN (WGAN)** introduces the Wasserstein distance as the objective function and constrains the discriminator to have a bounded Lipschitz norm, often using techniques like weight clipping, spectral normalization, or gradient penalties to enforce this constraint. Other variants include **Conditional GANs**, which allow generation conditioned on specific labels; **InfoGAN**, which maximizes mutual information to ensure disentanglement of latent factors; and **CycleGAN**, which performs translation between domains without requiring paired training data. Additionally, architectures like **StyleGAN** utilize progressive growing and style mixing to generate high-quality images with fine-grained control over style and texture.
