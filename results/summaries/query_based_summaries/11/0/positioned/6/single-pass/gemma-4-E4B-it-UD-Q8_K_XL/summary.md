**Generative Adversarial Network (GAN)**

A Generative Adversarial Network (GAN) is defined as a zero-sum game involving two players: a **generator** ($\mu_G$) and a **discriminator** ($\mu_D$). The generator aims to produce outputs whose distribution ($\mu_G$) closely matches a predefined reference distribution ($\mu_{ref}$), while the discriminator aims to distinguish between samples from $\mu_{ref}$ (which it should classify as real, outputting near 1) and samples from $\mu_G$ (which it should classify as fake, outputting near 0). The objective function for this game is $L(\mu_G,\mu_D) = \operatorname{E}_{x\sim \mu_{\text{ref}},y\sim \mu_D(x)}[\ln y] + \operatorname{E}_{x\sim \mu_G,y\sim \mu_D(x)}[\ln(1-y)]$, where the generator seeks to minimize this objective and the discriminator seeks to maximize it.

In practice, the generator synthesizes candidates from a latent space, and the discriminator evaluates them. Training involves applying independent backpropagation to both networks. GANs are implicit generative models; they do not explicitly model the likelihood function. While the theoretical equilibrium point suggests the generator perfectly mimics the reference and the discriminator outputs $1/2$ deterministically, in practice, training can suffer from issues like **mode collapse** (where the generator fails to cover all modes of the input data) or **vanishing gradients** (when the discriminator becomes too effective). Variants like Wasserstein GAN (WGAN) modify the discriminator's strategy set and use the Wasserstein metric to provide a better, more stable gradient for the generator.
