A **Generative Adversarial Network (GAN)** is a type of machine learning model that uses two neural networks — a generator and a discriminator — in a competitive, zero-sum game. The generator creates synthetic data that aims to mimic real data, while the discriminator evaluates whether the data is real or fake. The generator's objective is to produce data so realistic that the discriminator cannot distinguish it from real data, while the discriminator's goal is to correctly identify real versus fake data. This adversarial process drives both networks to improve iteratively.

GANs are implicit generative models, meaning they do not explicitly model the likelihood function or directly provide a latent variable for generating samples. They are often used for image generation, but also in other domains such as scientific simulations, medical imaging, and synthetic data creation. The original GAN formulation is prone to instability, mode collapse, and vanishing gradients, which have led to the development of variants like **Wasserstein GAN (WGAN)**, which improves training stability by using the Wasserstein distance and a Lipschitz-constrained discriminator. Other variants include **Conditional GANs**, which generate data based on additional information, and **Bidirectional GANs**, which enable translation between domains without paired data.

Key evaluation metrics for GANs include the **Inception Score (IS)** and **Fréchet Inception Distance (FID)**, which measure diversity and similarity of generated samples to real data, respectively. Despite their effectiveness, GANs face challenges such as difficulty in training, mode collapse, and the need for large datasets. They have been used for tasks like image enhancement, face generation, and creating synthetic medical images, but also raise ethical concerns regarding the potential misuse of fake media.
