## Generative Adversarial Network (GAN): Summary

A Generative Adversarial Network (GAN) is a framework comprising two neural networks—the generator and the discriminator—that compete in a zero-sum game. The generator's role is to synthesize data (e.g., images) that approximate a reference (real) distribution, while the discriminator aims to distinguish real samples from those produced by the generator. The objective function typically measures the similarity between real and generated samples, pushing the generator to mimic the reference data more closely. In practice, the generator learns to map random latent vectors to candidates resembling true data, and the discriminator evaluates these candidates. Training alternates between updating both networks via backpropagation. GANs are implicit generative models; they do not explicitly model the data likelihood and can generate full samples in a single pass. They are often used with convolutional architectures for image synthesis.

The GAN framework has spawned numerous variants, such as Conditional GANs, Deep Convolutional GANs (DCGAN), Wasserstein GAN (WGAN), and CycleGAN, each modifying architecture or objectives to address challenges like mode collapse, unstable convergence, and vanishing gradients. Notable innovations include curriculum learning, two time-scale update rules, and invertible data augmentation. Evaluation metrics for GAN performance include the Inception Score (IS), Fréchet Inception Distance (FID), and LPIPS. GANs have widespread applications in science (e.g., simulation and reconstruction), medicine (synthetic medical imaging), the arts, malicious content generation (e.g., deepfakes), and beyond. The foundational concept dates from the 1990s, gaining prominence with the 2014 formalization.
