## Generative Adversarial Network (GAN) Summary

A Generative Adversarial Network (GAN) is defined as a zero-sum game between two players: a generator ($\mu_G$) and a discriminator ($\mu_D$). The generator's objective is to approach the reference distribution ($\mu_{\text{ref}}$), while the discriminator aims to distinguish between samples from $\mu_{\text{ref}}$ (outputting close to 1) and samples from $\mu_G$ (outputting close to 0). In practice, the generator produces synthetic data candidates, and the discriminator evaluates them, creating a contest based on data distributions.

The core mathematical objective is given by $L(\mu_G, \mu_D):=\operatorname{E}_{x\sim \mu_{\text{ref}},y\sim \mu_D(x)}[\ln y]+\operatorname{E}_{x\sim \mu_G,y\sim \mu_D(x)}[\ln(1-y)]$. When using deterministic discriminator functions $D$, the optimal discriminator strategy tracks the likelihood ratio between the reference and generator distributions. The unique equilibrium point exists where the generator perfectly mimics the reference distribution ($\mu_G = \mu_{\text{ref}}$) and the discriminator outputs $1/2$ deterministically.

The GAN framework can be adapted in various ways, such as Conditional GANs, which allow conditional sample generation based on labels. Furthermore, variants like Wasserstein GAN (WGAN) modify the objective by using the Wasserstein metric, which provides better gradients for the generator. GANs are also susceptible to issues like mode collapse and vanishing gradients, which can be addressed through training strategies like the two time-scale update rule.
