# **Concise Summary:**

A **Generative Adversarial Network (GAN)** is a framework for training a generator to mimic a reference data distribution while a discriminator attempts to distinguish real samples from the generated ones. The system is defined as a zero-sum game where the generator's objective is to minimize the loss function, which is maximized by the discriminator. Ideally, at equilibrium, the generator perfectly mimics the reference distribution, and the discriminator outputs a constant value of 0.5, unable to distinguish between the two.

The original GAN objective relies on the Jensen-Shannon divergence, but this often leads to training instability, vanishing gradients, and mode collapse, particularly when the distributions are disjoint. The **Wasserstein GAN (WGAN)** addresses these issues by replacing the objective with the Wasserstein distance (Earth Mover's Distance) and constraining the discriminator (critic) to have a bounded Lipschitz norm. This modification provides stable gradients even when distributions are far apart and eliminates mode collapse. WGAN training requires specific techniques to enforce the Lipschitz constraint, such as weight clipping, spectral normalization, or gradient penalty, ensuring the critic remains a reliable signal for the generator's optimization.
