A **Generative Adversarial Network (GAN)** is a zero-sum game between two neural networks: a **generator** and a **discriminator**. The generator aims to create data that is indistinguishable from real data, while the discriminator aims to correctly identify real versus generated data. The game is defined over a probability space, with the generator's strategy set being a probability distribution over the space, and the discriminator's being a measurable function that outputs a probability between 0 and 1. The objective function is the expected log loss, which the generator minimizes and the discriminator maximizes.

The optimal discriminator, for a fixed generator, computes the **Jensen–Shannon divergence** between the generator's distribution and the reference distribution. The equilibrium point of the game is when the generator perfectly mimics the reference distribution and the discriminator outputs 0.5 for all inputs, indicating no ability to distinguish between real and generated data.

In practice, GANs are trained using a minimax game where the generator moves first and the discriminator moves second. This training process often leads to instability, such as **vanishing gradients** (when the discriminator becomes too good and the generator receives no learning signal) or **mode collapse** (where the generator produces only a limited subset of data, missing entire modes from the data distribution). To improve stability, techniques like the **two-time-scale update rule (TTUR)**, **Wasserstein GAN (WGAN)**, and **gradient penalty** are used. WGAN replaces the original loss with the **Wasserstein distance**, which provides a more stable gradient and mitigates mode collapse.

The original GAN formulation has been extended into various variants, including **conditional GANs**, **Wasserstein GANs**, and **hybrid models** like **VAE-GANs**, which combine the generative power of GANs with the latent variable modeling of variational autoencoders. These variants improve training stability, generalization, and the ability to generate diverse and high-quality samples.
